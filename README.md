![Python](https://img.shields.io/badge/Python-ETL-blue?style=for-the-badge&logo=python)

![License](https://img.shields.io/badge/License-MIT-green?style=for-the-badge)

An end-to-end **Business Intelligence & Financial Analytics** project built using **Python, SQL Server, and Power BI** that analyzes and compares the performance of major global stock market indices.

The dashboard enables users to monitor market performance, evaluate volatility, analyze trading volume, compare countries, and rank markets using a composite scoring model.

---

# 📌 Project Overview

Investment analysts require a centralized platform to compare multiple global stock markets and identify performance trends.

This project provides a complete analytics solution by integrating:

- Python ETL
- SQL Server Database
- SQL Views & Stored Procedures
- Power BI Data Modeling
- Advanced DAX Measures
- Interactive Dashboard Design
- Business Storytelling

- Trade Date
- Open Price
- High Price
- Low Price
- Close Price
- Trading Volume
- Market
- Country
